鉴生成图像取证研究图谱 · 数据方法

数据方法与质量边界

本页说明公开图谱如何采集、筛选、去重、核验与赋级。

收录范围

覆盖 AI 生成/合成图像检测、生成模型与来源归因、深度伪造与人脸操纵、图像篡改检测与定位、场景文本图像伪造、图像隐写与隐写分析、数字图像水印与认证，以及内容凭证和生成来源验证。纯 OCR、普通相机型号归因、只用合成图训练无关下游任务，以及音频、视频、文本隐写和纯文本生成检测不进入公开集。

采集与公开门槛

候选来自 OpenAlex、Crossref、arXiv、Semantic Scholar、DBLP 及经许可的种子记录。采集阶段偏向召回；只有标题或摘要明确陈述图像取证任务的记录才进入公开站。被挡下的记录仍保留在候选池供维护者复核，并按原因计入质量报告。

采集在 GitHub Actions 的 Collect papers 工作流中运行：候选池保存在 Actions 缓存中、不进入仓库；请求遇到限流或服务器错误时退避重试，同一来源连续失败 5 次即停止该来源，到达时间预算后保存已得结果。发布与全部校验、测试通过后，工作流才提交新的公开数据。

增量发布

每次发布都以当前公开数据为基线，与候选池中的新记录合并，再对全部论文（包括旧记录）重新执行范围判定、研究方向分类、渠道类型推断和等级匹配，因此规则更新会作用于整个图谱。候选池缺失时公开集不会缩小。维护者也可用 publish --fresh 只从候选池全量重建，此时作者别名历史会重新开始。

去重与来源链

依次使用 DOI、arXiv ID、OpenAlex 标识和标题+年份进行确定性合并。同名的预印本与正式版合并为一条，保留正式渠道、年份与 DOI；同一标题的不同正式渠道（例如 workshop 论文与其期刊扩展版）分别保留。模糊标题只进入人工队列，不自动合并。每篇公开记录保留数据源、原始标识、查询词和抓取时间。

发表年份与渠道类型

Crossref 把尚未出版的刊期文章登记为刊期年份（例如 2027 年），因此 Crossref 年份取在线发表、印刷出版和 issued 三个日期中最早的一个；若仍晚于 DOI 注册年份（created），改用注册年份。带 DOI 的论文以带注册日期的 Crossref 记录的年份为准，在全部合并完成后统一套用：Semantic Scholar 对有预印本的论文常给出 arXiv 年份，不用它改动年份；缺少这些日期字段的旧候选记录会在后续采集中按 DOI 补查。渠道类型由名称推断：预印本服务器记为预印本，含 conference、symposium、workshop 或会议论文集丛书名的记为会议，期刊名优先于来源自报的类型。

审核状态

verified 只能由人工确认产生；auto 表示自动收录、待人工复核；被拒绝记录不会导出。质量目标中的 300 篇核心集未达到时，报告会明确显示，不用自动记录冒充。

学术等级

CCF 只用于会议，只采用中国计算机学会第七版（2026）推荐目录，目录版本与官方来源随徽章展示。会议名称须与目录全称或缩写一致；全称嵌在论文集标题中时，其余部分只能是年份、届次、Proceedings、出版社名或会议缩写，避免把名称相近的其他会议（如 ICIP 与“International Conference on Image Processing, Computer Vision and Machine Learning”）误判为同一会议。workshop、findings 与 companion 论文集不继承主会等级，目录本身收录的 workshop（如 IH&MMSec）除外。期刊只使用中科院 2025 最后官方版或 Clarivate JCR 2026；明确拒绝 2026 年出现的“新锐期刊分区”。中科院/JCR 受限数据仅允许维护者导入其有权使用的数据，名称或 ISSN 无法可靠匹配时不赋级。综合检索表示“中科院一区或 JCR Q1”等并集，不生成虚构的综合等级。

本图谱仍是持续更新的 public preview，不构成完整 bibliography。元数据和自动分类可能有误，请以论文原始页面为准，并通过 GitHub Issues 反馈。
