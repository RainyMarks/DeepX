科研源

                
这些配置能让论文搜索、代码审计和 AI 分析更稳定；留空不会覆盖已保存密钥。

                

                  如何配置论文源和 AI
                  OpenAlex：填写 OpenAlex API key，用于开放论文库检索；未填时会自动降级到其他来源。
                  Semantic Scholar：填写 Semantic Scholar Graph API key，用于语义学术搜索、引用和开放 PDF 线索。
                  GitHub：填写 GitHub token，用于提高代码仓库搜索额度和审计稳定性，公开仓库搜索不需要私有仓库权限。
                  Crossref：填写常用邮箱作为 mailto，用于 DOI 元数据检索和礼貌访问。
                  AI 与联网搜索：模型密钥在“模型”页配置，Brave、Tavily、Serper、SearXNG 在“搜索”页配置。
